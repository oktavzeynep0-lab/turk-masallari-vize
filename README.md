# Türk Masalları Derlemesi - Vize Projesi

Bu depo, İstanbul Medipol Üniversitesi Görsel İletişim Tasarımı bölümü "Programlamaya Giriş" dersi vize projesi için hazırlanmıştır.

## Proje Hakkında
Anonim Türk halk anlatılarından seçilen 8 masalı içeren, internetsiz çalışabilen dijital bir masal kütüphanesidir. 
- Tamamen tek bir HTML dosyası (`tek.html`) içinde HTML, içsel CSS ve içsel JavaScript kullanılarak kodlanmıştır.
- Masal başlığına göre arama yapma, türe göre süzme ve okuma ekranında yazı boyutunu değiştirme özelliklerine sahiptir.
- CSS Grid ve Flexbox kullanılarak responsive (mobil uyumlu) olarak tasarlanmış, kitaplara 3D kapak açılma efekti eklenmiştir.
